## 伝えること（1 枚に収まる芯）

- 問題：AI に聞くために手が止まり、聞けば答えが出てくる。家庭教師は隣で気づいて、答えを言わない。でも高い。
- 解き方：机の横のスマホが手元を見ていて、20 秒止まったら声をかける。ヒントは 2 段階、答えはサーバが文字列で検査して止める。残すのは映像でなく詰まりポイント。
- 見せ場：壇上で本当に詰まり、沈黙の後に声がかかる。会場の全員も席の紙で同じ問題を解いていて、「答え、聞こえた人？」で証人になる。
- 締め：「答えを教える AI は、もうある。となりは、答えを言わない」

## 仕組みの説明（3 点に絞る）

1. **気づく**：ブラウザが 1 秒ごとにフレーム差分で動きを計算し、数字だけをサーバに送る。写真を送るのは、はじめたとき・次の問題に進んだとき・手が止まりかけたとき（詰まりの 3 秒前）・ボタンや声で呼んだときの 1 枚だけ。20 秒止まったら詰まりと判定する。
2. **答えを言わない**：ヒントは 2 段階。1 回目から答案を見て最初の誤りか次の一歩を示し、2 回目はもう少し具体的に言う（ADR 0029）。AI には同じ呼び出しで問題を解かせ、ヒント文にその答えや途中の値が含まれていれば、サーバが捨てて固定の問い返しに差し替える（ADR 0026）。
3. **ラベルを残す**：映像は既定で保存しない。残るのは「何問目で、何回、どの段階まで、詰まりポイントは何か」。「おわる」の後に同じ画面の「記録を見る」で見る。

## 競合比較

一言で言う差：**Photomath や ChatGPT のカメラは「聞かれて答える」。Khanmigo は「答えを言わないが、聞かれるのを待つ」。となりは「聞かれる前に気づいて、答えを言わない」。** そして紙を見ている。

| | Photomath / Qanda | ChatGPT・Gemini のカメラ／音声 | Khanmigo（Khan Academy） | タブレット型 AI 教材（atama+、Qubena など） | 家庭教師・個別指導 | となり |
|---|---|---|---|---|---|---|
| きっかけ | 学習者が写真を撮る | 学習者が話しかける | 学習者が打つ | 画面の中で出題 | 先生が気づく | **手が止まって 20 秒で気づく** |
| 答え | 解法と答えを出す | 聞けば出す | 言わない設計（ソクラテス式） | 解説を出す | 言わない | **言わないよう指示し、答えの文字列をサーバで検査** |
| 見ているもの | 写真 1 枚 | 映像（会話中） | テキスト | 画面内の操作 | 手元・表情 | **紙の手元（動きと、要るときの 1 枚）** |
| 紙の宿題 | 撮れば使える | 映せば使える | 使えない（打ち直す） | 使えない | 使える | **使える（初見の問題でよい）** |
| 保護者への記録 | なし | なし | 一部（学習ログ） | あり（画面内の正誤） | 口頭 | **詰まりポイントのラベル（終わった画面で、その回の分。日をまたぐ記録はこれから）** |
| 値段 | 無料〜月額 | 月額 | 月額 | 月額 | 月数万円 | スマホとスタンド |
| 弱いところ | 答え写しになる | 受け身。答えを言う | 受け身。紙を見ない | 紙を見ない | 高い | 確かめたのは中学の一次方程式。考えているだけでも声がかかる |

各製品の仕様は Web で読んだ範囲の理解で、細部は変わりうる。ピッチ前に下の一次資料で再確認する（2026-10-03 時点）。

- [Khanmigo（Khan Academy）](https://www.khanmigo.ai/)：答えを直接言わず導く設計の説明
- [Photomath](https://photomath.com/)：写真から解法を出す
- [Qanda（Mathpresso）](https://qanda.ai/)：写真から解法と解説
- [atama+](https://www.atama.plus/)：タブレット型の適応学習
- [Qubena](https://qubena.com/)：同上

## 実現可能性の材料（Hack Day 前は D の電話 1 本だけ。残りは 10/19〜22 の README 改善期間と Kaizen Sprint）

### 聞き取り（計画は 3 人。README には実施した分だけ書く）

- 相手：中学生 1 人、中学生の保護者 1 人、塾講師か家庭教師の経験者 1 人。
- 聞くこと：
  - （中学生）宿題で詰まったとき、何をするか。AI に聞いたことがあるか。答えを見た後、テストで解けたか。
  - （保護者）子どもがどこで詰まっているか、どうやって知るか。隣で見る時間はあるか。カメラが手元を撮ることへの抵抗は。
  - （講師）隣で見ていて「止まった」と思うのは何秒くらいか。最初に何と声をかけるか。答えを言わないためにどうしているか。
- 結果による分岐：
  - 「答えを見てしまう」「隣で見る時間がない」が多い → 芯の正しさの証拠として Award Day 版で使う。
  - 「カメラは嫌」が強い → 映像の扱い（手元だけ・保存しない・ラベルだけ）を場面 2 で先に言う構成に変える。作るものは変えない。00 の決定事項に書く。
  - 講師の「止まったと思う秒数」が 20 秒と大きく違う → `stuck_seconds` の既定値を変える。

### 外部の証拠（数字は必ず出典を確認してから使う）

- 紙の宿題の比率、家庭学習の時間：文部科学省の調査や、ベネッセ教育総合研究所の学習調査に該当項目がないか D が確認する。見つからなければ数字は言わず「聞いた範囲では宿題は紙だった」と言う。
- 家庭教師・個別指導の費用：文部科学省「子供の学習費調査」の補助学習費の項目を確認する。
- 中高生の生成 AI 利用：各種調査（内閣府・ベネッセ・民間）に「宿題で使う」の項目がないか確認する。
- 使うときは「○○の調査では」と出典を添える。数字を覚えていないものは言わない。

### 導入の形

- 専用機器なし。スマホとスタンドで始められる。
- 教材を選ばない。学習者が解いている紙の問題を、AI が写真から読んで解く（ADR 0026）。
- 記録は、「おわる」の後に同じ画面の「記録を見る」で見る。保護者に見せるときは学習者のスマホを渡す。日をまたいだ記録と保護者用のリンクはまだ無い（[Issue #98](https://github.com/jphacks/os_2601/issues/98)）。

## 想定質問と答え

| 質問 | 答え |
|---|---|
| ChatGPT のカメラモードと何が違うのですか？ | 向こうは聞かれて答え、聞けば答えを言います。となりは聞かれる前に気づき、答えを言いません。しかも「言わない」をプロンプトだけに頼らず、サーバでも検査しています。 |
| 考えているだけなのに話しかけられたら邪魔では？ | その通りで、動きの有無しか見ていないので区別できません。だから最初の声は「何を求めてる？」という問い返しにし、ヒントの後は黙ります。20 秒という秒数も沈黙の長さも設定で変えられます。解決の証明はしていません。 |
| 本当に答えを言わないと言えますか？ | 文字列としては言いません。サーバが正答の文字列と照合し、含まれていれば捨てます。「2 倍して 10 になる数」のような言い換えは止められません。そこは正直に制約として書いています。 |
| 手書きは読めるのですか？ | 読めないことがあります。読めないときは問い返しに落とす設計で、問い返しは答案が読めなくても成立します。Day 1 に実機で確認した結果（読めた枚数と遅延）を README に書きます。 |
| 子どもをカメラで撮るのですか？ | 撮るのは手元だけで、真上から撮るので顔は入りません。映像は毎秒ブラウザの中で処理して捨て、サーバに行くのは、手が止まったとき（17 秒）と、「ヒント」「できた」を押したとき、声で話しかけたときの 1 枚だけ、保存はしません。残るのは「移項の符号」のようなラベルだけです。ただしその 1 枚と、話しかけた文は AI の API に送ります（文も保存しません）。 |
| 学習効果はあるのですか？ | 証明していません。家庭教師が隣でやっていること（止まったら問い返す、答えを言わない）を真似ただけです。効果の検証は次の課題です。 |
| タブレット教材で良くないですか？ | 聞いた範囲では宿題は紙でした（実施した聞き取りの数を言う）。紙で解く以上、紙を見る必要があります。 |
| 市販の問題集では使えないのですか？ | 使えます。学習者の紙の問題を AI が写真から読んで自分で解き、その答えと照らしてヒントを検査します（ADR 0026）。ただし AI の読み違い・解き間違いがあり、そのときはヒントも外れます。 |
| なぜハードを作らなかったのですか？ | 家にあるスマホで動くことが実現可能性だからです。見た目のための箱は Kaizen Sprint で作ります。 |
| 事前に作っていたのでは？ | 事前は環境・アカウント・捨てコードでの検証・文書・ワークシートの印刷だけ。本番リポジトリの最初のコミットは 10/17 の朝です。 |
| 20 秒の根拠は？ | 聞き取りの講師の感覚と、自分たちで試した値です（結果が出たら差し替える）。秒数は学習者が始める前に 10 秒から 20 分の間で選べます。 |
| 複数の子どもがいたら？ | 今回は 1 台 1 人です。 |

## スライドの作り方（Award Day 版だけ。Hack Day 版はスライドを使わない）

- 1 枚 1 メッセージ、文字は大きく、図は 02 の Mermaid を画像化して使う。
- 色はデバイス画面と同じ（見守り中 緑、考え中？ 黄、となり 青）。
- 2 枚目「聞けば、答えが出てくる」には、写真→解答型アプリの画面の雰囲気（実物のスクリーンショットは使わない。自作の模式図）。
- 既知の制約のスライドを必ず入れる（審査員の信頼を得るため）。「考えているだけでも声がかかる」「言い換えは止められない」「教材は 3 枚」を自分から言う。
- Award Day 版は 10 枚以内。
