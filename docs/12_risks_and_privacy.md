# 12 リスクとプライバシー

**10/16 の改訂**：Hack Day 版では SSE・`events`・SQLite・Volume・`save_snapshots`・サムネイル・`quiet`・`away`・H3/H4 は作らない（02 の冒頭の注記）。下の表でそれらに触れている行は Kaizen Sprint 用に残してある。`signals` の途絶の判定は 5 秒。

設計レビュー（2026-10-03）の結果を保存したもの。README の「既知の制約」とピッチの Q&A の元になる。

## プライバシーの設計（何を撮り、何を送り、何を残すか）

| 段階 | 何が | どこへ | 残るか | 学習者に見えるか |
|---|---|---|---|---|
| 毎秒 | 映像（1280×720） | ブラウザの中。64×36 に縮小して差分を取り、捨てる | 残らない | 画面に映像を表示し続ける |
| 毎秒 | 動きスコア（数値 1 つ） | サーバ。`events` に `state.changed` として要約だけ | 状態の遷移だけ残る | 状態バッジ |
| 詰まった瞬間 | フレーム 1 枚 | サーバ → Gemini API（無料枠） | サーバには残らない。API 側は Google の規約で、無料枠では Google のサービス改善に使われうる（ADR 0025） | 「考え中？」の表示が合図 |
| 「できた」の瞬間 | フレーム 1 枚 | サーバ → Gemini API（無料枠） | 同上。読み取った最終答案の文字列は `checks` に残す（表示しない） | 「見てるよ」の表示 |
| ヒント時 | 詰まりポイントのラベル、段階、文、きっかけ（自動・ボタン・声） | JSON ファイル | 残る。記録画面の主役 | 記録画面 |
| 見守り中ずっと | マイクの音声 | ブラウザの音声認識（Chrome は Google、Safari は Apple のサーバ）で文字にする。「わからない」等を含むときだけヒント要求を送る | 音声も文字も残らない。`trigger: voice` だけ残る | 「聞こえた：わからない」が 3 秒出る |

### 守る 3 つの約束（画面・README・ピッチで言う）

1. **手元だけ**：真上から撮る。顔が入る角度にしない。印刷したワークシートの下部にも書く。
2. **保存しない**：映像もフレームもサーバに残さない。残すのはラベルと文。
3. **送る瞬間が分かる**：フレームが Gemini API に送られるのは「考え中？」と「見てるよ」が出た瞬間だけ。それ以外は数字しか出ていかない。Hack Day 版は無料枠なので、送った 1 枚は Google のサービス改善に使われうる。製品では学習に使わない有料枠にする（ADR 0025）。

### 言わないこと

- 「映像は外に出ません」→ 詰まった瞬間の 1 枚は API に送る。言わないと後で信頼を失う。
- 「匿名です」→ 手元の写真には筆跡・手・机の上の物が写る。「顔は映らない」まで。

## 設計上の判断（残すもの）

| 判断 | 理由 |
|---|---|
| 正答を GPT に渡さない（ヒント生成） | 渡さなければ言いにくい。1 層目の中で最も効く。正誤チェックの呼び出しだけ渡す |
| 答え漏れ検査は文字列照合まで | 2 日で確実に動き、説明できる。言い換えは限界として書く |
| 手の検出モデルを使わない | 2 日で確実に動くことを優先。「手がある」はヒント生成時に GPT に聞けば足りる |
| 正誤チェックは自動で走らせない | 自動で正誤を言うのは答えを言うのと同じ圧。「できた」を押したときだけ |
| `still` を画面で区別しない | 「止まっている」と数えられていることを見せると、カメラを意識して手を動かす |
| 映像は既定で保存しない | 保護者が見たいのは「どこで詰まったか」であって映像ではない。保存は明示的に ON |
| `scripted` は固定ヒントの再生 | GPT に賭けると本番で不発になりうる。使ったら言う |
| ハードを作らない | スマホで動くことが実現可能性。見た目は Kaizen Sprint |

## README の「既知の制約」に転記する文

```
## 既知の制約

- 詰まりの判定は「手元の動きが選んだ秒数（10 秒〜20 分、既定 20 秒）ない」というヒューリスティックです。考えているだけでも声がかかります。最初の声を問い返しにし、ヒントの後は黙る設計（秒数は設定）で緩和していますが、解決の証明ではありません。
- 「答えを言わない」は、AI に同じ呼び出しで問題を解かせ、その答えの文字列とヒント文をサーバが照合して守っています。AI が解き間違えると、この検査も外れます。「2 倍して 10 になる数」のような言い換えは止められません。
- 問題は学習者の紙の問題（初見）で、AI が写真から読んで解きます。読み違い・解き間違いがあり、そのときはヒントや正誤も外れます。
- 手書きの読み取りは生成 AI（Gemini）の画像理解に依存し、照明や筆圧で失敗します。失敗時は問い返しに落とします。
- 映像は手元だけで、保存しません。ただし、詰まった瞬間と「できた」を押した瞬間の 1 枚は Google の Gemini API に送られます。Hack Day 版は無料枠を使っているので、送った 1 枚は Google のサービス改善に使われることがあります。製品では学習に使われない有料枠にします。
- 席を立ったことは検知しません。手が止まれば問い返しの声がかかります。
- 「わからない」の聞き取りはブラウザの音声認識で、音声は Chrome なら Google、Safari なら Apple のサーバで文字にされます。聞き取った文字は保存せず、ヒントを呼んだ記録だけ残ります。
- 音声はブラウザの音声合成で、端末によって声が違います。
- scripted モードは AI を使わず固定の問い返しを再生します。使ったときはピッチで言います。
```
