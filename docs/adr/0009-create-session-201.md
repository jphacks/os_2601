# 0009. POST /sessions は 201 を返す

- ステータス: 承認
- 日付: 2026-10-17

## 文脈

`docs/03` は成功時のステータスを書いていない。`web/lib/api.ts` は `response.ok`（200〜299）で成功を判定するので、どちらでも画面には影響しない。

## 検討した選択肢

1. セッション作成だけ 201、ほかの成功は 200
2. 成功はすべて 200

## 決定

選択肢 1。

## 理由

- REST の慣習どおりで、`tools/create_session.py` のログやブラウザの開発者ツールで、作成と取得を見分けられる

## 受け入れたトレードオフ

- FastAPI のルートに `status_code=201` を書く 1 か所が増える

## 再検討する条件

- なし（画面に影響しないため）
