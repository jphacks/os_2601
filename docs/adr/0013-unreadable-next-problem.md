# 0013. 読めなかった check の next_problem_no は今の番号にする

- ステータス: 提案
- 日付: 2026-10-17

## 文脈

`docs/03` の check の応答の `next_problem_no` は、`correct` なら次の番号（最後の問題なら null）、`incorrect` なら今の番号と書いている。`unreadable`（読めなかった）のときの値は書いていない。

## 検討した選択肢

1. 今の番号（`incorrect` と同じ）
2. null

## 決定

選択肢 1。

## 理由

- null は「最後の問題が正解で終わった」の意味なので、読めなかったときに使うと B の `/device` が終了と取り違える
- 読めなかったときは問題を進めない（問題は `working` のまま）ので、今の番号が実際と合う

- なし
