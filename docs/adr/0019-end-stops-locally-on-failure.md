# 0019. end() は postEnd が失敗しても手元のループとカメラを止める

- ステータス: 提案
- 日付: 2026-10-17

## 文脈

T1-2 の文は「end: postEnd → 停止 → stopCamera」。回線が落ちている（「つながりにくいみたい」が出ている）ときに「おわる」を押すと、postEnd が失敗してループもカメラも止まらず、手元で終える手段が無い。

## 検討した選択肢

1. postEnd を試し、成否にかかわらず手元のループとカメラを止めて onState に ended を渡す。エラーは呼び出し元に投げ直す
2. postEnd が成功したときだけ止める（文のまま）

## 決定

選択肢 1。読み上げも止める。

## 理由

- 学習者が「おわる」を押したら、画面とカメラは必ず終わるべき
- サーバ側のセッションは signals が途絶えれば watching に戻るだけで、害が無い。必要ならオペレータが `/ops` から end できる

## 受け入れたトレードオフ

- 回線が落ちていると、サーバでは ended にならず `/log` で進行中に見える

## 再検討する条件

- `/log` の集計で、終わっていないセッションが邪魔になったとき
