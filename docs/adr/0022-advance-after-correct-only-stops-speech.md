# 0022. 正解の読み上げ中の「次へ」は、読み上げを止めるだけにする

- ステータス: 承認
- 日付: 2026-10-17

## 文脈

`docs/03` の advance は「前の問題を skipped にする（done なら変えない）。speaking なら読み上げを打ち切って watching」。check が correct のとき、サーバはすぐ次の問題を working にして `current_problem_no` を進め、「正解」を読み上げる speaking に入る。この読み上げ中に学習者が「次へ」を押すと、始まったばかりの次の問題が skipped になり、さらに 1 問進む。最後から 2 問目なら、そのままセッションが終わる。

## 検討した選択肢

1. correct の後の speaking の間の advance は、問題を進めずに読み上げを止めて watching にする
2. docs のとおり、今の問題を skipped にして進める

## 決定

選択肢 1。correct の後の speaking かどうかは、メモリだけのフラグで持つ（保存しない）。

## 理由

- 学習者が「正解」の途中で「次へ」を押すのは、次の問題に行きたいからで、その問題はもう始まっている
- `/log` に「解いていないのに飛ばした」問題が出ると、保護者が読む記録が事実と違う

## 受け入れたトレードオフ

- 「次へ」の結果が、押した瞬間の読み上げの中身で変わる

## 再検討する条件

- 「次へ」で 2 問進めたいという要望が出たとき
