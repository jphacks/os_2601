# 0024. Vercel のプレビューは保護を外して公開する

- ステータス: 承認
- 日付: 2026-10-17

## 文脈

Vercel の Hobby は、既定で本番以外のデプロイの URL に「Vercel Authentication」を掛け、Vercel にログインしていないと開けない（302 でログイン画面へ）。`docs/06`・`docs/11` は、B・C・D がスマホでの確認を Vercel のプレビュー URL で行うことにしている（`http://<PCのIP>:3000` ではカメラが取れない）。B・C・D は Vercel のチームに入っていない。

## 検討した選択肢

1. プレビューの保護を外し、URL を知っていれば誰でも開けるようにする
2. 保護したまま、B・C は PC の localhost で確かめ、iPhone での確認は main に入ってから本番 URL で行う

## 決定

選択肢 1（`vercel project protection disable tonari --sso`）。

## 理由

- プレビューは `NEXT_PUBLIC_MOCK=1` で動き、API の鍵も正答も入っていない
- リポジトリ自体が公開なので、プレビューで見えるものはすでに誰でも読める
- iPhone でしか出ない不具合（カメラ・音声）に、マージ前に気づける

## 受け入れたトレードオフ

- プレビューの URL が漏れると、作りかけの画面を誰でも開ける

## 再検討する条件

- プレビューに鍵や本物の API の URL を入れるようになったとき
