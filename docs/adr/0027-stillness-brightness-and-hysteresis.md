# 0027. 動きのスコアから明るさの変化を除き、静止を抜ける境目を高くする

- ステータス: 承認
- 日付: 2026-10-17

## 文脈

10/17 15:44〜15:47 の本番 iPhone（立てて固定、τ 0.03）で、手を止めているときのスコアは 0.02〜0.03 に 61 回、0.03〜0.04 に 12 回集まっていた。τ との差がほとんど無く、少しの揺れで「動いた」になって 20 秒がやり直しになる。高橋も「止めているのに認識していないことが結構ある」と感じた。

考えられる原因は 2 つ。

- iPhone のカメラが明るさとピントを自動で合わせ続け、画面全体が少し明るく・暗くなる（蛍光灯のちらつきも同じ）。今のスコアは画面全体の差の平均なので、これがそのまま乗る。
- ペンを持った手の小さな震え。書いているとき（0.04 以上）よりずっと小さい。

## 検討した選択肢

1. A と B の両方
   - A：毎秒のフレームから画面全体の平均の明るさを引いてから差を取る（`web/lib/motion.ts`）
   - B：静止に入るのは τ（0.03）未満のまま、静止を抜けるのは `motion_exit_threshold`（0.045）以上にする（`api/app/state.py`）
2. A だけ
3. B だけ
4. τ をさらに上げる

## 決定

選択肢 1（高橋が選んだ）。B の値は `api/settings.yaml` の `motion_exit_threshold: 0.045`（τ の 1.5 倍）。

## 理由

- A は全体の明るさの揺れを消すので、止めた手のスコアを下げて τ との差を広げられる。契約も状態の規則も変えない
- B は小さな震えでは静止を途切れさせず、書き始め（0.04 以上）では抜ける。τ そのものを上げる（選択肢 4）と、静止に入るのも甘くなり、ゆっくり書いているのに「考え中？」が出やすくなる

## 受け入れたトレードオフ

- A：画面の一部だけが明るさを変える場合（手の影がかかる、など）は消えない
- B：静止の間に 0.03〜0.045 の小さな動きを続けても、静止として数え続ける。ゆっくり小さく書き直していると、「考え中？」が出ることがある
- docs/04 の遷移の表の「still → watching：motion ≥ τ」が「motion ≥ motion_exit_threshold」に変わる

## 再検討する条件

- 会場の照明（19:10 に測る）で、止めた手のスコアが 0.03 を超えるとき
- 書いているのに「考え中？」が出ると、テストで分かったとき
