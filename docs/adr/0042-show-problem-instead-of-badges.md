# 0042. 画面の上には、状態やシート名でなく、AI が読み取った問題文を出す

- ステータス: 承認
- 日付: 2026-10-18

## 文脈

`/device` の左上に状態のバッジ（「見守り中」「考え中？」「おつかれさま」）を、ヘッダにシート名と問題番号（「FREE 自由な問題」「1 / 20 問目」）を出していた。学習者の紙の問題を読む形（ADR 0026）にしてから、シート名は見えないはずのワークシート、20 は枠の数で、どちらも学習者には意味が無い。状態はキャラクターの表情と字幕で分かる。10/18 の本番で高橋が気づいた（#50・#52）。

## 決定

- ヘッダから、シート名と問題番号を外す。残すのは scripted の黄色帯と「つながりにくいみたい」だけ
- 状態のバッジを外し、その場所に AI が読み取った問題文を出す。読み取る前は何も出さない
- 問題文はサーバが記録していたが画面に渡していなかったので、ヒントの応答と `GET /sessions/{id}` の `problems[]` に `problem_text`（読み取る前は null）を足す（足すだけなので画面は壊れない）

## 理由

- AI が何を問題として読んだかが見えると、読み違いに学習者がその場で気づける
- 「考え中？」のバッジは、先読み（ADR 0028）で詰まりとほぼ同時にヒントが届くようになり、出ている時間は声の合成の 1〜2 秒ほどだった

## 受け入れたトレードオフ

- 今の状態（見守り中か、黙っている間か）を文字で確かめる手段が無くなる。デバッグ用は `?debug=1` で静止の秒数を出す
