# 作業の始め方

1. root の `.role.local` を読んで自分の役割を確かめる（b / c / d / takahashi）。無ければ作るように私に言う。
2. `docs/tasks/<役割>.md`（b は `b.md`、c は `c.md`、d は `d.md`）を読み、今の時刻に当たるカードを 1 つ選んで、カード名と完了条件を 3 行で言う。
3. そのカードの「Claude Code に渡す文」があれば、それをこれから実行する文として確認する。無ければ、作るものを 1 部品（1 ファイル）に絞って提案する。
4. 触るファイルの一覧を先に出す。ハーネスと依存のファイル（`docs/11` の「触ってよいもの」）が混ざっていたら外す。
5. `git status` を見て、`main` にいるなら `git switch -c <役割>/<短い名前>` でブランチを切る。別のブランチにいるならそのまま。
6. 私が「進めて」と言うまで、ファイルは変えない。
